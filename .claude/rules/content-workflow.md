# Content Creation Workflow

When creating a new post:
1. **ALWAYS** read `@src/content/posts/CLAUDE.md` first
2. **ALWAYS** use English file name for any post
2. Create Chinese version: `xxx.md` from `@template.md`
3. Create English version: `xxx.en.md` with identical frontmatter except `lang: en`
4. Both files must be created before completing the task
